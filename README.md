# expense-tracker-bot

Асинхронный Telegram-бот на Python для контроля личных расходов. Проект находится в стадии активной разработки (MVP готов).

🛠 Стек технологий
Язык: Python 3.12

Фреймворк: Aiogram 3 (асинхронность, FSM)

База данных: SQLite (модуль sqlite3)

Инструменты: Git, работа с REST API, настройка обхода блокировок (Cloudflare Worker).

⚙️ Реализованный функционал (на данный момент)
Добавление трат: Диалог с ботом с использованием FSM (Finite State Machine). Валидация ввода даты (включая кнопку «Сегодня»), категории и суммы.

Статистика: Вывод общей суммы, максимальной траты и среднего расхода в день за период.

Просмотр списка: Вывод последних трат с привязкой к конкретному пользователю (user_id).

Удаление: Удаление конкретной записи по её уникальному ID (с проверкой принадлежности пользователю).

Защита: Валидация текстового ввода, защита от пустых сообщений и отправки стикеров/файлов. Параметризованные SQL-запросы (защита от инъекций).

🗺 Планы по развитию (Roadmap)
□ Добавление главного меню с Reply-кнопками (UI/UX).
□ Перевод удаления трат на Inline-кнопки (без ввода ID вручную).
□ Нормализация базы данных (переход на 3 таблицы: users, categories, expenses).
□ Добавление визуализации данных (построение графиков через matplotlib).
□ Переход на асинхронную работу с БД (aiosqlite).

📁 Структура проекта
main.py — точка входа, запуск бота.

config.py — конфигурация, настройка бота и прокси.

database.py — слой работы с базой данных (SQL-запросы).

functions.py — вспомогательные утилиты (валидация).

handlers/ — папка с роутерами (разделение логики по файлам: старт, добавление, статистика, удаление).

🚀 Как запустить локально
Клонируйте репозиторий.

Создайте виртуальное окружение и установите зависимости:
pip install -r requirements.txt

Создайте файл .env и добавьте токен бота (и URL прокси, если требуется).

Запустите бота:
python main.py
