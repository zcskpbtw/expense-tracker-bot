# Expense Tracker Bot (Telegram)

Асинхронный Telegram-бот на Python для контроля личных расходов. Проект представляет собой полноценный MVP с интерактивным интерфейсом и локальной базой данных.

Стек технологий
Язык: Python 3.12

Фреймворк: Aiogram 3 (асинхронность, FSM, роутеры)

База данных: SQLite (модуль sqlite3)

Инструменты: Git, настройка обхода блокировок (Cloudflare Worker).

Реализованный функционал
Интерактивное меню: Управление ботом через ReplyKeyboardMarkup (кнопки «Добавить», «Статистика», «Список», «Удалить»), а также поддержка текстовых команд.

Добавление трат: Пошаговый диалог с использованием FSM. Валидация ввода даты (включая быструю кнопку «Сегодня»), категории и суммы. Возможность отмены действия на любом шаге.

Статистика: Вывод общей суммы, максимальной траты и среднего расхода в день (с защитой от деления на ноль).

Просмотр списка: Вывод всех трат пользователя с их уникальными ID.

Удаление: Удаление конкретной записи по ID (с проверкой принадлежности пользователю) и функция полной очистки истории с подтверждением действия.

Безопасность и отказоустойчивость: Валидация текстового ввода (защита от стикеров/файлов), параметризованные SQL-запросы (защита от инъекций), привязка данных к user_id.

🗺 Планы по развитию (Roadmap)
□ База данных: Нормализация (переход на 3 таблицы: users, categories, expenses).
□ UI/UX: Перевод удаления трат на Inline-кнопки (без ввода ID вручную).
□ Визуализация: Построение графиков (круговая/столбчатая диаграмма) через matplotlib.
□ Тестирование: Покрытие слоя работы с БД тестами (pytest).
□ Асинхронность: Переход на асинхронную работу с БД (aiosqlite).

Структура проекта
main.py — точка входа, запуск бота.

config.py — конфигурация, настройка бота и прокси.

database.py — слой работы с базой данных (SQL-запросы).

keyboards.py — централизованное создание клавиатур для UI.

functions.py — вспомогательные утилиты (валидация текста).

handlers/ — папка с роутерами (разделение логики: старт, добавление, статистика, удаление, fallback).

🚀 Как запустить локально
Клонируйте репозиторий.

Создайте виртуальное окружение и установите зависимости:
```
bash
pip install -r requirements.txt
```
Создайте файл .env в корне проекта и добавьте токен бота:

env
BOT_TOKEN=ваш_токен_от_BotFather
PROXY_URL=ваш_url_прокси_если_требуется
Запустите бота:
```
bash
python main.py
```
